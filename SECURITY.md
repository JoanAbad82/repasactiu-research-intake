# Security Policy

## Scope

This repository is a public research-intake surface. It must not contain production credentials, private student data, private course material, private source mappings, answer keys, or production secrets.

## Reporting

Do not open public issues containing sensitive information. Report security-sensitive concerns privately to the repository owner.

## External input

All external submissions are treated as `UNTRUSTED_EXTERNAL_INPUT`. Do not require maintainers or agents to execute downloaded code, shell commands, browser automation, external-agent instructions, or unknown dependencies to understand a proposal.

## Production boundary

This repository has no deployment, secrets, or automatic write/promotion path into Repàs Actiu production. Any production-relevant finding requires independent reproduction and validation in the production repository.
