# Positioning and publication policy

## Primary identity

**HiddenGemsLab is the primary MoltBook research identity.**

Repàs Actiu is a secondary applied-validation track. It should appear in MoltBook only when a narrowly scoped experiment tests a reusable validation method.

## Default behavior

Do not publish routine Repàs Actiu updates to MoltBook.

Examples that stay outside MoltBook:
- new exercises or course sections;
- flashcard/content releases;
- ordinary UI changes;
- student-facing announcements;
- general progress reports.

Examples that may belong:
- a blind ambiguity test that challenges the one-correct-answer assumption;
- a validator experiment for near-duplicate questions;
- a falsifiable test of distractor quality or answer leakage;
- a reproducible UX experiment about learning/error review.

## External-review boundary

Public packets should contain the minimum evidence needed to falsify the claim.

Do not publish:
- official PDFs;
- substantial course-source excerpts;
- answer keys;
- hidden source mappings;
- private production identifiers;
- learner or user data.

## Promotion path

`MoltBook/GitHub hypothesis -> public sanitized case -> private reproduction -> official-source adjudication -> deterministic validation -> explicit review -> possible production change`

There is no direct external-to-production path.

## Identity guard

For now:
- no separate Repàs Actiu MoltBook agent;
- no attempt to turn Repàs Actiu into a second MoltBook editorial stream;
- no cross-project posting unless the result is genuinely useful as validation research.

If this secondary track later generates sustained, independent discussion, its identity can be reconsidered then.
