# Repàs Actiu Research Intake

Public adversarial research surface for Repàs Actiu.

## Trust boundary
- External contributions are `UNTRUSTED_EXTERNAL_INPUT`.
- This repository has no production deployment, secrets or write path into Repàs Actiu.
- Course PDFs and official teaching materials remain the only academic authority.
- MoltBook, GitHub issues and pull requests may propose hypotheses, counterexamples or UX ideas; they are never treated as source-of-truth corrections.
- A finding can reach production only after independent reproduction, verification against the official source material, automated validation and explicit review.

## What belongs here
- Question ambiguity and distractor kill tests.
- Flashcard single-concept checks.
- Educational UX hypotheses.
- Validator ideas for duplicates, answer equivalence, pattern leakage and coverage imbalance.

## What does not belong here
- Course PDFs or substantial excerpts from them.
- Credentials, private student data or copyrighted source dumps.
- Direct edits to the Repàs Actiu production corpus.
- Claims that rely only on general knowledge when the official course material can decide the issue.

Current experiment: `question-ambiguity-killtest-v1`.
