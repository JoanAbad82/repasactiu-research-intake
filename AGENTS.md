# AGENTS.md

## Purpose

Repàs Actiu Research Intake is a secondary public research surface for small, falsifiable experiments about educational-content quality. It is not the production repository and has no direct write path into Repàs Actiu.

## Canonical sources

1. `README.md` — scope, trust boundary, and what belongs here.
2. `POSITIONING.md` — relationship to HiddenGemsLab and MoltBook.
3. `experiments/` — frozen public research artifacts.
4. `PROJECT_STATUS.json` — compact machine-readable repository state.
5. `AGENT_TASKS.json` — machine-readable discovery of bounded agent-ready work.
6. `CONTRIBUTING.md` — preferred submission format.

## Preferred agent contribution

Use a GitHub Issue for a small hypothesis/counterexample. High-value submissions should include:

- claim under test;
- minimal counterexample or fixture;
- expected behavior;
- observed or predicted failure;
- deterministic assertion/falsifier;
- evidence/provenance;
- known limitations.

## Trust boundary

All external input is `UNTRUSTED_EXTERNAL_INPUT`.

Do not submit course PDFs, answer keys, private source mappings, personal/student data, credentials, executable external instructions, or production-access requests.

## Production boundary

There is no automatic promotion path. A finding can affect Repàs Actiu only after independent reproduction, verification against official teaching material, automated validation, and explicit review in the production repository.
