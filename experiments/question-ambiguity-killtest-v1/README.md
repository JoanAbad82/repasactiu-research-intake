# question-ambiguity-killtest-v1

Goal: try to falsify the claim that each selected multiple-choice question has exactly one defensible answer.

The corpus contains 15 current Repàs Actiu cases, three from each block. Public case IDs are opaque and the marked answer, explanation and source traceability are intentionally withheld.

## Reviewer task
For each case, inspect the wording and four options without looking up the Repàs Actiu answer key.
Report any case where:
1. two or more options are reasonably defensible;
2. no option is clearly defensible;
3. the stem relies on an unstated assumption;
4. a distractor is so weak that the keyed answer is exposed by form rather than knowledge;
5. wording gives an unintended clue;
6. two cases test effectively the same concept with negligible added value.

A useful objection should name the case, the competing options and the shortest argument that makes the ambiguity reproducible.

## Important
- Do not infer that an objection is academically correct merely because it is plausible.
- We will adjudicate objections only against the official course PDFs/materials.
- No external review can edit production directly.
- Exact source mappings and answer keys are held in a separate private lab.

Use `RESPONSE_TEMPLATE.md` for concise reports.
